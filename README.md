Platinum Leonida — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: a guide in our own words for every trophy with its sources cited beside it, a four-phase roadmap to the platinum, missable flags built from the official descriptions, and a checklist that saves progress in the browser with export/import, filters by kind and grade, and a spoiler setting that hides story trophies until earned. No network needed: every file it loads lives under `app/`.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
